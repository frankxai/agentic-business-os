# Agentic Business OS (Reusable Foundations)

Existing foundation in the FrankX ecosystem (https://github.com/frankxai/agentic-business-os).

**General**: Agent harness, quality gates, compounding business memory, website/agent orchestration for AI-native companies.

**PV-Lager / Rial Alliance Extensions** (added via this collaboration):
- Intelligent customer intake (quiz + recommendation) as core business process
- Sales + marketing intelligence layers tied to physical products (Zola Car Pods, hybrid climate)
- Virtual layer (Wix MCP) + domain modeling (Energy IS PV instance)
- Ops automation for family business (cousin MD, accounting agents, logistics)
- Mass adoption playbooks using swarms for affection/engagement

**Reusability**: Patterns here serve Starlight, Arcanea, FrankX, GenCreator, and now the PV-Lager alliance. Work in this repo advances the OS generally; pv-lager-agentic shows concrete application to a stocked solar structural + hybrid climate business.

See pv-lager-agentic for full applied architecture, quiz, swarms, and interconnections.
