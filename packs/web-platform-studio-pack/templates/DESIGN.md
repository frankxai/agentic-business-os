# Design direction

Status: awaiting project-specific decisions and review.

## Audience and purpose

Describe the visitor, their immediate job, one primary action, and the evidence they need to trust it. Include real content examples and the shortest complete journey.

## Art direction

Choose typography roles, spacing rhythm, contrast, image language and one distinctive interaction. Name references and the specific qualities being studied. Record exclusions that prevent generic output and brand confusion.

## Tokens and components

Document color roles, font licenses/fallbacks, type scale, spacing, radii, borders, shadows and content widths. List components with keyboard, focus, disabled, loading, empty, validation, error and success behavior. Use sentence case.

## Motion and responsive behavior

Explain each motion's purpose. Define cancellation/rapid interaction behavior and reduced-motion alternatives. Touch must not depend on hover. Record narrow, medium and wide layout decisions using representative content.

## Asset and review register

Record each asset's source, rights, exact prompt where generated, output path and reviewer. Check logo at small sizes, mono, light/dark, favicon, social crop and print if promised. Record visual review findings and their fixes with screenshots tied to the revision.
