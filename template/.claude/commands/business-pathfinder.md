# /business-pathfinder — one process to one proof

**Usage:** `/business-pathfinder <experience, idea, or business process>`

## Pipeline

1. Read business memory and current decisions.
2. Dispatch `@opportunity-architect`.
3. Select one route: student, restart, founder, agency, or SME.
4. Produce one process-to-offer spec and three evaluation cases.
5. Surface the spec for human approval before implementation.
6. On approval, use `@product-architect` for any new surface and build the smallest proof.
7. Run claims, typecheck, build, and relevant security/visual gates.
8. Update business memory with the result and next decision.

Never turn the output into an income promise, a swarm by default, or an unattended production workflow.
